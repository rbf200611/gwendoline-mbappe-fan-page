# Kylian Mbappé — Fan Tribute

A premium, unofficial and non-commercial Kylian Mbappé fan tribute created by **Gwendoline Tatah**.

The site celebrates Mbappé's journey from Bondy and Clairefontaine through Monaco, Paris Saint-Germain, France and Real Madrid, with a timeline, major moments, records and a personal tribute.

## Site files
- `index.html` — main website
- `styles.css` — responsive visual design
- `script.js` — scroll reveals, counters, progress bar and mobile navigation
- `favicon.svg` — KM site icon
- `.nojekyll` — tells GitHub Pages to publish the static files directly

## Publishing with GitHub Pages
This is a static HTML/CSS/JavaScript site and can be published directly from the `main` branch and repository root.
